# Profile Card Project 🖼️

## 📖 Overview

This project is a **simple and elegant profile card** designed using HTML and CSS. It showcases basic web design principles with clean structure and styling.

## 🚀 Features

- **Responsive Design**: Optimized for different screen sizes.
- **Customizable**: Easily adapt colors, fonts, and layout.
- **Lightweight Code**: Minimal and efficient HTML/CSS for faster loading.

## 💻 Technologies Used

- **HTML**: For structuring the content and elements.
- **CSS**: For styling and layout design.

## 🌐 Live Demo

You can check out the live profile card by clicking [here](https://iqbalmajdi.github.io/Profile-Card1/).

## 🌟 How to Use

1. Clone or download the repository.
2. Open the `.html` file in your browser to view the profile card.
3. Edit the `.css` file to personalize the design.
